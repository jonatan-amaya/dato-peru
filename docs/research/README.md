# Investigación de usuarios · DatoPerú

Notas de las 3 conversaciones con usuarios potenciales. **Importante:** estas
notas deben salir de conversaciones REALES del founder (en persona, llamada o
mensajes). Este archivo documenta el guion usado y la estructura; las notas
finales de cada conversación se completan abajo.

## Guion de conversación (10 min)

1. ¿Cuál fue la última vez que necesitaste una cifra oficial (BCRP, INEI,
   municipalidad)? ¿Para qué la usaste?
2. ¿Cómo la conseguiste? ¿Cuánto te tomó?
3. ¿Qué fue lo más tedioso o riesgoso del proceso?
4. ¿Alguna vez citaste/publicaste una cifra y luego dudaste de si estaba
   actualizada o bien sacada? ¿Qué pasó?
5. Si existiera un asistente que te la dé en 5 segundos con la fuente citada,
   ¿lo usarías? ¿Pagarías por él? ¿Cuánto?
